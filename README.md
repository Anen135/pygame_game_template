# Pygame Game Template

Готовый шаблон небольшой 2D-игры на Pygame.

## Что уже есть

- Главное меню
- Игровая сцена
- Пауза
- Game Over и рестарт
- Управление WASD / стрелками
- Стрельба мышью
- Игрок, враги, пули
- Коллизии
- HP, счёт, таймер
- Простая камера shake при получении урона
- Звуки выстрела, попадания, урона и UI
- Регулировка громкости
- Масштабируемая структура по папкам
- Никаких внешних картинок не требуется

## Установка

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Управление

- `WASD` / стрелки — движение
- ЛКМ — выстрел
- `ESC` — пауза / назад
- `R` — рестарт после поражения
- В меню: мышь или клавиатура

## Куда развивать

Шаблон специально сделан без сложного движка и без сторонних ассетов:
можно заменить отрисовку фигур на спрайты, добавить TileMap, анимации,
инвентарь, NPC, сохранения, уровни и т.д.
